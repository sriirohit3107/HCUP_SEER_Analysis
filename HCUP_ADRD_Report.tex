\medskip
\noindent\textbf{Primary admission reason:} In NIS, \texttt{I10\_DX1} (principal diagnosis)
is the condition chiefly responsible for the admission — this is the primary admission reason
variable. There is no separate free-text field.

\medskip
\noindent\textbf{Prior fall:} Since NIS cannot link admissions across visits (see Q3),
prior fall history is captured via ICD-10-CM code \textbf{Z91.81}
(\textit{personal history of falling}), coded by the provider at the current admission.

\noindent F03.x (unspecified dementia) already covers general dementia patients.
Any of the above codes in \emph{any} diagnosis position qualifies the discharge as ADRD.

% ── Q3: Patient identity ─────────────────────────────────────────────────────
\section*{3. Multiple Admissions for the Same Patient}

\begin{tcolorbox}[colback=lightgray, colframe=hcupblue!60]
\textbf{Yes — the same patient can appear multiple times.}
NIS assigns a unique \texttt{KEY\_NIS} per \emph{hospitalization}, not per patient.
There is no patient-level identifier in the NIS public-use file.
Our cohort counts represent \textbf{hospitalizations}, not unique individuals.
This is a fundamental NIS limitation and will be stated in the manuscript.
\end{tcolorbox}
